Throughout the internship, I worked on an in-depth Restaurant Data Analysis project using Python, Pandas, Seaborn and Matplotlib. The project involved:

Conducting Exploratory Data Analysis (EDA) and Visualization Analysis to uncover key insights.

Analyzing top cuisines, city insights, and price range distribution.

Investigating online delivery offerings and ratings patterns.

Exploring cuisine combinations, restaurant chains, and geographic patterns.

Performing review analysis, examining the relationship between review length and ratings, and analyzing votes vs. ratings.

Visualizing the correlation between price range, services offered, and customer ratings.

This project has significantly enhanced my data analysis and visualization skills. I look forward to applying these skills in future data-driven projects!
